# Frightertainment typography

The interface uses four Google Fonts families: Barlow Condensed, Bebas Neue and DM Sans are the existing utility/display/body faces; Cormorant Garamond is the new editorial display face used for page titles, featured titles, chart film titles and text-led film covers. A browser requests the stylesheet directly on every HTML document, so typography does not depend on a previous page visit.

Cormorant Garamond is distributed by Google Fonts under the **SIL Open Font License 1.1**. The project source is [Google Fonts, `ofl/cormorantgaramond`](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond), with the [OFL text](https://github.com/google/fonts/blob/main/ofl/cormorantgaramond/OFL.txt). The other existing families are also published by Google Fonts under OFL; their upstream families remain unchanged.

Cormorant Garamond falls back to Georgia and the browser's serif family. Barlow Condensed and DM Sans retain their existing sans-serif fallback stacks. No font binaries are copied into the repository. If Google Fonts cannot load, text remains reflowable and readable using local fallbacks.

## Gothic cinema display font

The Movies and Indie Movies title displays use **Grenze Gotisch** by Omnibus Type / Renata Polastri, licensed under the SIL Open Font License 1.1. Google Fonts hosts the font; fallback is Georgia. Source: https://github.com/Omnibus-Type/Grenze-Gotisch . This font is reserved for prominent headings; body copy remains DM Sans for accessibility. The original Frightertainment logo remains unchanged.
