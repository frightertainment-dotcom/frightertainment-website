# Frightertainment typography

The site uses Times New Roman with system serif fallbacks for readable text on desktop and mobile. The Frightertainment wordmark remains the brand logo. Supplied transparent title artwork is used for the Movies, TV Shows, Cinema, Indie Movies, Podcasts and Games section headings; each image is decorative inside an accessible text heading.

## Seven-destination update — 13 October 2026

The seven destination compositions now use system UI text for body copy and controls, with Grenze Gotisch reserved for selected display headings. The original Frightertainment logo and supplied transparent section wordmarks remain the primary brand lettering and remain inside accessible text headings. Secondary archive and detail templates retain their existing serif rules unless a shared component requires the updated type. The former blanket `!important` Times New Roman rule in `hub.css` was removed so component typography can render as specified.
